# Data_projects_TripleTen
## 📂 TripleTen Data Science  Projects

Below is a collection of the core projects I completed during the TripleTen Data Science Program. Each project demonstrates real-world analytical skills, business thinking, and data-driven problem solving.

| # | Project Title | Description |
|---|--------------|-------------|
| 1 | **Instacart Customer Behavior Analysis** | Performed exploratory data analysis on a large grocery delivery dataset to understand customer purchasing patterns, reorder behavior, and product popularity. Generated insights to help improve marketing strategies and personalized recommendations. |
| 2 | **IMDB Movie Review Sentiment Analysis (NLP)** | Built a natural language processing model to classify movie reviews as positive or negative. Applied text preprocessing, TF-IDF vectorization, and machine learning algorithms to achieve strong F1 performance. |
| 3 | **Customer Segmentation (Clustering Analysis)** | Applied unsupervised machine learning techniques such as K-Means clustering to segment customers based on purchasing behavior and identify meaningful customer groups. |
| 4 | **Anomaly Detection in Business Data** | Used machine learning methods such as K-Nearest Neighbors and Isolation Forest to detect abnormal patterns in sales and profit data, helping identify potential operational issues. |
| 5 | **Computer Vision: Age Prediction Model** | Developed a deep learning model using convolutional neural networks to predict a person's age from facial images. Implemented image preprocessing and neural network training techniques. |
| 6 | **Final Project – Telecom Customer Churn Prediction** | Built a machine learning model to predict customer churn for a telecom company. Conducted extensive data cleaning, feature engineering, and model evaluation. The final Gradient Boosting model achieved **AUC-ROC ≈ 0.92**, enabling the company to identify customers at risk of leaving and improve retention strategies. |
