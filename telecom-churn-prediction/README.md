# Telecom Customer Churn Prediction

## Project Overview
This project develops a machine learning model to predict customer churn for a telecom company.

## Business Problem
Customer churn reduces revenue and increases the cost of acquiring new customers. The goal of this project is to identify customers at high risk of leaving so the company can take action early.

## Dataset
The dataset includes customer-level information such as:
- Contract type
- Monthly charges
- Tenure
- Internet service
- Payment method

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data cleaning
2. Exploratory data analysis
3. Feature engineering
4. Model training
5. Model evaluation

## Results
The final Gradient Boosting model achieved an AUC-ROC score of approximately 0.92.

## Key Insights
- Customers with month-to-month contracts were more likely to churn.
- Higher monthly charges were associated with greater churn risk.
- Customers with longer tenure were less likely to leave.

## Business Impact
This model can help the company identify at-risk customers and improve retention strategies through proactive outreach and targeted offers.
